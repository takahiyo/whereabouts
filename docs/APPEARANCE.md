# 共通デザインと端末の外観設定

更新: 2026-10-04。devの既存GUIへ適用。管理5領域の機能統合とは別の表示改善。

## 操作

メイン画面の「外観」からデザインを選ぶ。管理パネルの「基本 → 外観の設定」、ログイン画面の下部からも選べる。選択はすぐ反映され、同じブラウザの次回表示にも使われる。

| 外観 | 特徴 |
|---|---|
| パステル（既定） | 明るいカードと柔らかな青緑 |
| クラシック | 紺、アイボリー、見出しの明朝系文字 |
| メタリック | 銀色の面とグラデーション、スチールブルー |

ログイン、主メニュー、グループジャンプ、在席表、管理/閲覧モーダルで色・枠・ボタンを共通化する。テーマは業務情報の意味を変えない。行事カレンダーのカテゴリー/休日の色と印刷の配色は従来仕様を維持する。

## 状態とグループ

在席状態は行/カードの背景色、左のライン、ステータス欄の文字で示す。カードの白背景による状態色の上書きを解消した。在席/外出/会議/在宅/出張/研修/健診/ドック/帰宅/休みの既存クラスを使う。独自ステータスで既存色クラスのないものは中立色と文字で表示し、勝手に業務分類を変更しない。

グループは見出しの帯・番号・名称・登録人数で区切る。ジャンプメニューにも同じ色を使う。色は表示順に6色を循環する補助であり、グループ固有の保存属性ではない。グループ順を変えると対応色も変わる。色だけで識別する必要はなく、名称と番号を併記する。

## 保存と影響範囲

- `whereabouts-appearance`に外観ID一つだけをlocalStorageへ保存。拠点/個人/名簿の情報を含まない。同じブラウザの他タブでもstorageイベントで追従する。
- ログアウト後も端末の外観を保持。別ブラウザ・別端末・別originへは共有しない。
- 保存できない場合はそのページ内だけで切り替え、保存できない旨を表示。未知の保存IDはパステルへ戻す。
- DOMを再描画せずhtml属性を変更するため、テーマ切替で入力途中の値や選択を失わない。
- 認証・権限・API payload・共有D1/KV・Cron・カラム設定の保存処理は変更しない。
- `appearance.css`は画面専用。旧CSSを並べ替えず最後に読み込み、印刷用CSSへテーマを持ち込まない。

定義は`js/constants/appearance.js`、保存キーは`js/constants/storage.js`、操作は`js/services/appearance.js`、配色は`appearance.css`。動きを減らすOS設定にも追従する。
